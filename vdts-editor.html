テキストで一括入力（台詞・カメラ）
台詞・カメラを行単位でまとめて書く。ここに書くとシートに、シートを触るとここに反映される
台詞欄（始まり｜終わり｜だれ｜なに。0+01 が1コマ目。話者に (M)/(OFF)/(N)、効果音は SE）
例: 0+01 | 1+00 | 太郎 | おはよう
カメラ欄（始まり｜終わり｜前｜動き｜後。動きは FIX / PAN / T.U / T.B / Follow / F.I / F.O / O.L / SL か自由文）
例: 0+01 | 1+00 | A | PAN | B
使い方
  • VDTS は、バージョン管理を組み込んだ XDTS。保存のたびに版が重なり、いつでも遡れる。XDTS / TDTS はそこから書き出す
  • 数字のマスをタップ — その場で書き直す。打った文字は即反映。別の所を触ると閉じる。Esc で元に戻す
  • 原画と原画の間の線をタップ — 中割 ○ を付ける／外す
  • ×の途中、または最後の原画より後をタップ — そのコマから新しい番号を書く
  • 長押し（右クリック） — そのコマから新しい番号を書く
  • 数字や×を上下にドラッグ — 変化点を動かす（指の場合は長押ししてからドラッグ）
  • 台詞・カメラの空きをタップ — ブロックを置いて書く。端をドラッグすると伸縮、真ん中をドラッグすると移動
  • 列名をタップ — 改名。＋ — 列を追加
  • 尺 — 上段の尺をタップして書き換えるか、シート末尾の ⇕ を上下にドラッグする。赤線が尺の終わり
  • 尺編集 — 青いフレーム線から線へドラッグして範囲を選び、切る／伸ばす
  • 余尺 — 頭と尻にコマを足す。足した行は薄いグレー。尺の表示は総尺
  • 動画欄を更新 — 原画の番号と中割から動画番号を振り直す。動画欄のマスは原画欄と同じ操作で直せる
  • コマ番号をタップ — 修正指示・申し送り・要確認を書く（列と種類はチップで選び、範囲は −／＋で決める）
  • 上段のメモ欄 — 描画領域。ペンで引けば線、タップすると文字を書く。右上で色（黒／赤／青／緑）・太さ（細／太）、「消」で線をなぞって消す。下端をドラッグで高さを変える。線は版と一緒に残る
  • 上書き保存 — 名前・役・ひとことを付けて版を1つ重ねる。版 N — 過去の版を表示する
  • 作品名・話数・シーン・カットを書き換えると、ボタンは「新規保存」になり、元のファイルには上書きせず新しい .vdts に保存する（元のファイルはそのまま）
  • CSP から持ち込む — CSP EX の ファイル → アニメーション書き出し → タイムシート情報 で xdts を保存。「取り込み」でその xdts を選ぶと、今のシートの原画欄を差し替えて版を1つ重ねる（履歴・指示・動画欄はそのまま）。画面に落とした場合は別の文書として開く
