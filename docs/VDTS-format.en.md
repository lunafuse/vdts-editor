# The VDTS format v0.1 (versioned Digital Time Sheet)

VDTS is a **master** format for animation timesheets. One file holds the current state, every hand-off as a version (history), correction notes (朱 — "red pencil"), handwritten strokes, and the original files it was imported from. XDTS / TDTS are derived exports.

## File

- Extension `.vdts`, UTF-8
- Line 1 is the identifier `versionedDigitalTimeSheet Save Data` (same convention as XDTS / TDTS); JSON from line 2

## Structure

```json
{
  "format": "vdts",
  "version": "0.1",
  "cut": { "title": "", "episode": "", "scene": "", "cut": "", "author": "", "memo": "", "memoHeight": 150, "fps": 24 },
  "sheet": {
    "duration": 48, "slackHead": 0, "slack": 0,
    "layers":   [ { "name": "A", "cells": ["1","1","1","SYMBOL_TICK_1","1","2", "…"] } ],
    "douga":    [ { "name": "A", "cells": ["1","1","1","2","2","3", "…"] } ],
    "dialogue": [ { "from": 1, "to": 24, "speaker": "Taro", "kind": "", "text": "Morning", "lane": 0 } ],
    "camera":   [ { "from": 1, "to": 48, "kind": "PAN", "fromLabel": "A", "toLabel": "B", "text": "", "lane": 0 } ],
    "ink":      [ { "id": "k1", "zone": "memo", "color": "shu", "width": "thin", "who": "", "role": "", "at": "…", "points": [ { "fx": 0.2, "y": 0.3, "p": 0.6 } ] } ]
  },
  "history": [
    { "id": 1, "at": "2026-08-19T10:00:00+09:00", "who": "name", "role": "原画", "note": "imported: x.xdts", "fingerprint": "sha256:…", "sheet": { "…full snapshot, same shape…" } }
  ],
  "annotations": [
    { "id": "a1", "kind": "shusei", "who": "name", "role": "作監", "at": "…", "anchor": { "layer": "A", "komaStart": 3, "komaEnd": 5 }, "text": "tighten by 2 frames", "state": "要", "madeAgainst": 1, "resolvedIn": null }
  ],
  "extensions": { "xdts": { "source": "x.xdts", "text": "…verbatim original…" } }
}
```

### `cut` — the header strip of the paper
`title`, `episode`, `scene`, `cut`, `author`, `memo` (typed text of the memo area), `memoHeight` (memo/drawing area height in px), `fps` is fixed at 24. For display and file names, numeric episode/scene are zero-padded to 2 digits and cut to 3.

### `sheet` — current state
- `duration` main length in frames; `slackHead` / `slack` extra frames (slack) at head and tail. Total = `slackHead + duration + slack`
- `layers[]` key-drawing (原画) columns. `cells` is **frame-expanded** (length = total; index 0 = frame 1). A hold is a run of equal values. Empty cell is `"×"`. Inbetween marks are `SYMBOL_TICK_1` / `SYMBOL_TICK_2`
- `douga[]` inbetween (動画) columns, same shape; generated by numbering keys and ticks sequentially, and editable
- `dialogue[]` `from`/`to` are 1-based frames, `speaker`, `kind` is `""` (ON, lip-sync) / `M` (monologue) / `OFF` (off-screen) / `N` (narration) / `SE` (sound effect), `lane` 0/1 = S1/S2
- `camera[]` `kind` is one of `FIX` `PAN` `T.U` `T.B` `Follow` `F.I` `F.O` `O.L` `SL` or empty (free text in `text`), `fromLabel`/`toLabel` are frame names, `lane` 0/1 = CAM1/CAM2. `tdtsCode`, if present, is the TDTS instruction code (unknown codes are preserved as-is)
- `ink[]` handwritten strokes as vectors. `zone:"memo"` = memo area, coordinates relative to its width/height (`fx`, `y`), `p` = pressure

### `history[]` — versions (append-only)
Every save adds one entry. `sheet` is a full snapshot; `fingerprint` is the document fingerprint (normalized cell fingerprint + douga + dialogue + camera + ink + header). Restoring an old version also appends a new version — history is never rewritten.

### `annotations[]` — correction notes
`kind` is `shusei` (correction) / `moushiokuri` (hand-over note) / `kakunin` (needs check). `anchor` is **layer name + frame range** (never a track index, so it survives tools that rebuild tracks). `madeAgainst` = version the note was written against, `resolvedIn` = version that resolved it, `state` = `要` (open) / `済` (done).

### `extensions`
Verbatim text of imported originals (`xdts` / `toei` for tdts). Never discarded.

## Normalized cell fingerprint
Drop layers that are entirely empty, sort layers by name, join as `duration=48;A=1,1,1,…;B=…`, SHA-256. It stays identical across "reconstructive" exporters such as CLIP STUDIO (track reordering, padding with empty tracks) as long as timing and cel numbers are unchanged.

## Mapping to XDTS / TDTS
- XDTS: the minimal version-5 document CLIP STUDIO itself writes (`header` / `timeTables` / `version`). `duration` is the total length, frames are 0-based change points, empty is `SYMBOL_NULL_CELL`. Dialogue and camera go to fieldId 3 / 5 in the same shape as TDTS (value on the first frame, `SYMBOL_HYPHEN` on every continued frame)
- TDTS: the version-7 shape of Toei's Digital Timesheet. Wrapped in `timeSheets[]`; `header.episode` is `abbr#episode` (`title` + `#` + `episode`), `operatorName` ← `author`, `direction` ← `memo`. Optionally writes history as `sheet2, sheet3…`
- Strokes, notes and history have no vocabulary in XDTS / TDTS and are not exported
